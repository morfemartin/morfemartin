## Hi, I'm Martin Morfe

### I build brands for clothing labels — from the logo to the tech pack to the website.

- **Currently building** [TechPack AI Builder](https://github.com/morfemartin/techpack-ai-builder) — an open-source, multi-garment tech pack (ficha técnica) generator with AI-assisted intake and translation.
- **Running** Morfe Studio — branding, textile development, tech packs and websites for clothing brand launches, idea to launch.
- **Exploring** AI tooling for fashion production: local model orchestration, layout engines, SVG pipelines.
- **Open to collaborate** on open-source tools for fashion, design systems and creative automation.
- **Ask me about** branding, garment tech packs, JavaScript, SVG.
